You are going to be given a series of XML elements that represents a portion of a terminal session interspersed with numbers on empty lines. The XML elements each represent an event in a terminal session. These elements can be either <user_input> (representing user keyboard presses or cut-and-paste buffer pastes) or <system_output> (representing responses from software). Each XML element includes a timestamp id (in seconds) that indicates how much time has passed between when the session started, and when the event occurred. Each element other than the last is followed by a number.

Your overall task is to help identify sequences of elements which represent higher-level communications, representing what is being communicated in full. A higher-level communication consists of sequences of XML elements followed by numbers, where a whole communication starts at 0, and the numbers increment until the communication is complete.The sequences should consist of one or more consecutive events (either <user_input> or <system_output>) that together form a logical unit of work, or convey of a single idea. think: a command, a response to a command, a system message, a keyboard shortcut, an escape sequence redrawing a menu, etc. 

Expected Output:
You will accomplish the overall task by simply responding to the last element in the user input given to you with either the number immediately following the number given to the prior element, or when you believe that the last element is clearly not a part of the same higher level communication as the previous elements, then you are to reply with 0.

Your input may start with an incomplete region, which is to say, not start with an entity, followed by 0. When this is the case, you can infer that the first higher-level communication you see in the input is not complete, and may not paint the whole picture of what was happening during that region.
