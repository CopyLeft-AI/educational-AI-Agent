Your task is to identify higher level communications in your input stream, and determine whether the final element you are given is a part of the prior higher level communication, or begins a new one.

Examples include:
 * A command
 * A response to a command
 * A system message
 * A complete keyboard shortcut
 * An escape sequence that redraws a menu item
 * A series of backspaces correcting a typo

A higher level communication is a series of elements with the same group number. A higher level communication begins when a new `group_number` appears, and ends when a higher `group_number` follows. When a higher level communication is complete, it will immediately be followed by the first element which is part of the next higher level communication, with a `group_number` one higher than the previous.

An element in a higher level communication can either be `<user_input>` (representing user keyboard presses or cut-and-paste buffer pastes) or `<system_output>` (representing responses from software). Each element includes a `timestamp` (in seconds) that indicates how much time has passed since the session began. Elements which are part of the same higher level communication will each have the same `group_number`.

You will be given a series of elements that each represent a communication in a terminal session, each with a `group_number`. Group numbers are unique, increase sequentially, and identify separate higher level communications (though they may not start at 0).

Your input will end with two elements. The first element is the last part of the prior higher level communication (with a `group_number`), and the final one is the one you will evaluate (with no `group_number` assigned).

Your task is to determine whether the final element belongs to the same higher level communication as the one before it, or starts a new one.

How to Respond:
Return one of the following:
 * The previous `group_number` — if the final element continues the previous higher level communication.
 * `NEW` — if it begins a new higher level communication.

Your response should always consist of a single word: either a group number, or `NEW`.
