Your task is to identify higher level communications in your input stream, and judge whether a the final element you are given is a part of the prior higher level communication, or not.

Examples of the types of higher level communications we are trying to identify are:
a command,
a response to a command,
a system message,
a keyboard shortcut,
an escape sequence which redraws a menu item,
a series of backspaces correcting a typo

A higher level communication is represented by of sequences of single elements with a group number entity, where a complete higher level communication starts with a single element with a group number different then the prior elements, and ends where the next higher level communication starts. When a higher level communication is complete, it will immediately be followed by the first element which is part of the next higher level communication, with a group number one higher than the previous group.

An element inside of a higher level communication can either be <user_input> (representing user keyboard presses or cut-and-paste buffer pastes) or <system_output> (representing responses from software). Each element includes a timestamp id (in seconds) that indicates how much time has passed between when the session started, and when the communication occurred. Following elements which are part of the same higher level communication will each have the same group number

You are going to be given a series of elements that each represent a communication in a terminal session, each with a group number. After this list of elements with group numbers, you are going to be given a single element without a group number, for identification.

Your task is to identify if the last element you are given in the input set is part of the yet-incomplete higher level communication immediately preceeding it.

You will accomplish your task by responding to the final element presented to you with either the group number of the prior element (indicating it is part of the same higher level communication), or when you believe that the final element is clearly not part of the same higher level communication as the preceeding sequence of elements, then you are to reply with NEW, indicating this element should be the start of a new higher level communication.

Your input will end with two elements. One of these is the last element that is known to be a part of the prior higher level communication, and the second one is the one you will judge. The element from the prior higher level communication will have been assigned a group number.
