You are going to be given a (possibly empty) series of XML elements that represents a portion of a terminal session, each preceeded by numbers on an empty line indicating which line number in a higher level communication the following element represents. After this list of Elements and line numbers, you are going to be given a single element, for identification. The XML elements each represent a single communication in a terminal session. These elements can be either <user_input> (representing user keyboard presses or cut-and-paste buffer pastes) or <system_output> (representing responses from software). Each XML element includes a timestamp id (in seconds) that indicates how much time has passed between when the session started, and when the communication occurred.

A higher level communication is represented in the input by of sequences of XML elements each preceeded by numbers, where a complete communication starts with a '0' on a new line, followed by a single XML element on the next line. Following XML elements that are a part of the same sequence are each preceeded by incrementing positive numbers indicating their place in the sequence until the higher level communication is complete. When a higher level communication is complete, it is immediately followed by a single '0' on a new line, followed by the first entity which is not directly a part of the same idea or concept. There are no end markers; every higher level communication's beginning is so me other higher level communication's end.

Your task is to identify if the last entity you are given in the input set is a part of the yet-incomplete higher level communication immediately preceeding it.

Examples of the types of ideas or concepts we are trying to identify are:
a command,
a response to a command,
a system message,
a keyboard shortcut,
an escape sequence which redraws a menu item,
a backspace correcting a typo

You will accomplish your task by responding to the final element with either the number immediately following the number given to the prior element (indicating it is a part of the same higher level communication), or when you believe that the final element is clearly not a part of the same higher level communication as the preceeding sequence of elements, then you are to reply with '0'. If there was no preceeding sequences of elements provided, then you have been presented with the first element of a sequence, and should also to reply with '0'.

Your input may start with an incomplete higher level communication, which is to say, it not start with a '0'. When this is the case, you can infer that the first higher level communication you see in the input is not complete, and may not convey enough of the idea to assist with contextualizing later elements.
